# Specs

The spec-driven-development documents this app was built from, written in Kiro
before the code existed.

| File | What it is |
|---|---|
| `requirements.md` | The numbered requirements and their acceptance criteria — what the site has to do, and what counts as done. |
| `design.md` | The design that answers those requirements: data model, sections, aesthetic direction. |
| `tasks.md` | The implementation plan the build followed, task by task. |

They describe the January 2026 build and are kept as the record of *why* the app
is shaped the way it is — they are not maintained alongside the code, so where a
document and the code disagree, the code is what ships.

They lived in the parent folder until September 2026, in a second git repository
that was never pushed anywhere. They are here now so they share the app's
history and its remote.
